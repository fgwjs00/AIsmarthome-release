# 轻主机 AI 助手使用说明

本插件支持 **ARM64 (`aarch64`，如 PK3566 轻主机)** 与 **X86_64 (`amd64`，如 Intel N100/J4125 迷你主机、NAS、PVE/VMware/Unraid HAOS)** 双架构，是为 Home Assistant OS 打造的全品牌 AI 智能家居助手。

## 快速开始

1. 启动本插件，勾选「在侧边栏显示」，点击打开 **AI 助手** 页面（仅限 Home Assistant 管理员账号访问，`panel_admin: true`）。
2. 进入「模型与回滚」标签页，填入**通义千问（DashScope）API Key**（或切换其他兼容大模型）并点击保存，无需重启插件即可生效。
3. 在「AI 创作台」直接用自然语言：
   - **创建并现场试调场景**：*"帮我建一个客厅观影场景，主灯关掉，灯带调到 20% 暖光，格力空调开 26 度静音风"* → 点击草稿卡片上的「⚡ 现场试光预览」，不满意继续口语微调，满意后点「✔ 确认写入 HA」；也可点「↩ 恢复试前状态」。
   - **抓拍当前状态存场景**：先把家里灯光空调调好，直接说 *"把客厅现在的状态保存为会客模式"*。
   - **创建跨品牌联动自动化**：*"出门后关掉全屋空调和灯，5分钟后让石头扫地机开始清扫"*。
   - **自动化诊断排错**：*"帮我看看晚归开灯自动化为什么刚才没触发"*（AI 自动读取 HA 执行轨迹 Trace 定位原因）。
4. 在「快速配网」标签页：
   - 一键开启 Zigbee 入网（自动兼容 ZHA 与 Zigbee2MQTT 及 EFR32/CC2652/ConBee 等协调器）；
   - 查看局域网自动发现的设备（如格力空调、HomeKit、Yeelight）一键绑定；
   - 通过全品牌向导添加米家、石头扫地机、美的、涂鸦、海尔等品牌集成。

## 安全与权限说明

- **仅限 Home Assistant 内部运行（Ingress 隔离）**：本插件在 HAOS 下仅响应 Home Assistant 官方 Ingress 代理（`172.30.32.2`）转发的已登录会话请求，自动拒绝局域网任何设备对 `:8099` 端口的外部直连访问。
- **人机权限分离（L3 物理安防保护）**：涉及门锁、水气阀门、安防警报等高风险（L3）操作及系统维护工具，禁止大模型自动确认，必须由用户在 Home Assistant 界面卡片上手动点击二次确认（一次性加密令牌校验）。
- **权限用途说明**：`homeassistant_config:rw` 用于管理场景/自动化/扩展组件与读取 HomeKit 配对状态；`hassio_role: manager` 与 `addons:rw` 用于一键部署与拉起 Zigbee2MQTT、Mosquitto 与本地 Matter 跨生态网桥。
